\begin{abstract}

This report presents the design, implementation, deployment, and performance evaluation of a serverless image processing application developed using Amazon Web Services (AWS). The application allows users to upload images through a REST API and perform image processing operations using AWS Lambda functions. The deployment uses API Gateway, Lambda, Amazon S3, and CloudWatch services.

The main objective of the project is to evaluate the scalability and performance of serverless computing under different workload conditions. Experimental tests were conducted using varying numbers of concurrent users and requests. Metrics including response time, throughput, invocation count, execution duration, concurrency level, and error rate were collected and analyzed.

The obtained results demonstrate the ability of AWS Lambda to automatically scale according to workload intensity while maintaining acceptable performance levels. A cost analysis is also presented and compared with alternative deployment solutions.

\end{abstract}

The workflow is summarized as follows:

\begin{enumerate}
\item User uploads an image.
\item API Gateway receives the request.
\item Lambda function processes the request.
\item Image is stored in Amazon S3.
\item Processed image is returned to the user.
\end{enumerate}

\subsection{AWS Components}

\subsubsection{API Gateway}

API Gateway exposes REST endpoints used to upload and process images.

\subsubsection{AWS Lambda}

Lambda functions execute image processing operations without requiring dedicated servers.

\subsubsection{Amazon S3}

S3 stores both input and processed images.

\subsubsection{CloudWatch}

CloudWatch is used to collect monitoring and performance metrics during experimental testing.

\section{Implementation}

\subsection{Upload Service}

The upload endpoint receives an image encoded in Base64 format and stores it in Amazon S3.

\subsubsection*{Endpoint}

\begin{verbatim}
/upload-base64
\end{verbatim}

\begin{verbatim}
{

"folder": "small",
"content_type": "image/jpeg",

This project demonstrated the deployment of a serverless image processing application using AWS Lambda.
